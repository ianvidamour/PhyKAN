# Legacy Experiments

This directory contains earlier PhyKAN experiments, notebooks, utilities, datasets, and exploratory implementations retained for reference.

The contents are not maintained as a single runnable package. Many scripts rely on local relative paths, old data layouts, or files generated by earlier experiments. For new work, start with one of the documented top-level experiment folders in the repository root. Before running a legacy script, inspect its imports, working-directory assumptions, and input/output filenames.
